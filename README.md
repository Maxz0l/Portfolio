# Portfolio - Enzo Lorandi

Portfolio d'ingénieur CPE Lyon, spécialisé en robotique de service : électronique, systèmes embarqués, robotique et IA appliquée.

**Site en ligne : [maxz0l.github.io/Portfolio](https://maxz0l.github.io/Portfolio/)**

Site statique en HTML / CSS / JavaScript pur (aucun framework, aucune étape de build), hébergé sur GitHub Pages. La couche 3D de l'accueil (bras robotique procédural, Three.js) et les animations de scroll (GSAP + Lenis) sont vendorisées en local.
